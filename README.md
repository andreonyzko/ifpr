# 📚 Repositório IFPR

Este repositório contém exercícios, projetos e materiais desenvolvidos durante o curso técnico no Instituto Federal do Paraná (IFPR).

## 🗂 Estrutura do Repositório

A estrutura está organizada por áreas temáticas, facilitando a navegação e o acesso aos conteúdos:

- **web development/**: Projetos e exercícios relacionados ao desenvolvimento web.
- **desktop development/**: Aplicações e exercícios focados em desenvolvimento para desktop.

## 🧑‍💻 Tecnologias Utilizadas
O repositório abrange diversas tecnologias e linguagens de programação, incluindo:

- HTML, CSS e JavaScript
- Java
- SQL
